# 🛠️ Scrimba JavaScript Challenges

This repository serves as a centralized "Mega Repo" containing a collection of interactive frontend mini-projects built during the Scrimba JavaScript course. The core objective is to master vanilla JavaScript fundamentals, event handling, and dynamic DOM manipulation.
